# 0.15.4：登录背景流场视觉 + 推送运营商名完整显示

这一版两件事：**登录页和初始化向导的背景重做**成了流场艺术视觉；**推送里的
运营商名不再被砍成半截**。另附 CI 发布链路的加固。

---

## 一、登录页 / 初始化向导背景：流场视觉

背景重做为流场（flow field）艺术视觉：

- **3D Perlin 噪声场**驱动，z 轴随时间演化，6000 粒子沿场流动；
- **日落八色渐变**，粒子按生命值三档透明度，`lighter` 合批描线；
- 新增**暗角层**（vignette）：压四角、焦点收中心，且不拦截鼠标交互；
- 底色 `#120e18` → `#07070c`，整体更沉；
- 互动**只保留指针尾流** —— 参考稿里的种子重生成 / 保存 PNG / R/S 快捷键 /
  信息面板刻意没有做：登录页要输主密码，快捷键会抢输入。

> 作用范围仅限**登录前**（登录页 / 初始化向导）。登录后的主界面背景不受影响。

## 二、修复：推送运营商名显示不全

**现象**：推送通知里运营商一栏是「🏢 Hytron Network Services Limi…」——
名字被砍成半截。

**根因**：`src/ip-lookup.js` 的 `normIsp()` 按字符数硬截断到 28。
`Hytron Network Services Limited` 是 31 个字符，于是被砍成
`Hytron Network Services Limi…`。

这个截断是**旧版式**的遗留：当时 IP / 归属地 / 运营商挤在同一行，钉钉窄屏会
折行，所以给运营商留了很小的额度。而这三项早已改成各占一行，运营商独享整行
宽度，28 字符的额度没有存在必要。

**修复后**：运营商名完整显示，例如 `Hytron Network Services Limited`；
既有的「剥 AS 号」「多值取第一个」行为不变。同时新增一条自检守卫，
防止截断被顺手加回来。

## 三、工程：CI 发布链路加固

复盘 0.15.3 发布当天的事故（手动发布绕过了更新包签名，导致客户端拒绝更新）：

- release job 检出代码时显式拉取 tag —— 否则草稿会建到无 tag 的名字上，
  签名正文进不了线上 Release；
- 新增守卫：tag 上已有已发布的 Release 时直接失败，发布必须是
  「CI 建草稿 → 人工核对 → 点发布」这一条路。
