# 0.16.1：桌面专属任务正式上线，并给它装上「自动刹车」

这个版本把此前一直置灰、标着「测试中 · 延迟上线」的**桌面 Rewards 应用专属任务**正式开放。
它在 11 月 7 日到 18 日之间连续六次真机验证过：真实点击、真实到账，服务器侧活动进度确实上涨。

同时给它加了一套失效保护——**连续多次跑不通就自动关掉开关**，不再每轮白跑两分钟、
也不再反复重启你开着的 Rewards 应用。

---

## 一、桌面应用专属任务正式开放

有些活动标着「必须在本应用内完成」，用软件自带浏览器去做一律不计分：程序化导航会被
Bing 附加 `dmreload=1`，服务端判定为非用户主动访问。所以这类任务走的是另一条路：
驱动微软 Rewards 桌面应用，通过真实鼠标点击打开活动页，由应用自己完成归因上报。

- 任务入口在「任务全局设置 → 桌面应用专属任务」，**默认关闭，需要自己打开**。
- 每完成一项会复查服务器上的活动进度，只按真实涨了的项计分；「点了但没到账」不会被算成完成。
- 兑换类的「最后领取」阶段自动化点不动，现在直接跳过并在汇总里写明「需人工领取」，不再每天白试。
- 当天点过没到账的项会记入当日跳过清单，第二天自动失效重试。

> ⚠️ **运行时会先关闭并重启你当前开着的 Rewards 桌面应用**，这是为了拿到一个干净的、
> 带调试端口的实例。如果你正在那个应用里做别的事，请先保存。

## 二、连续失效自动熔断

连续 3 次跑不通（应用起不来、调试端口接管失败、未安装、桌面应用未登录）会自动关闭该任务开关，
并推送一条说明告诉你原因和重新打开的位置。

- 跑通一次立刻清零；你手动重开后会自动「重新武装」，重新给 3 次机会。
- 「今天没有可做项」「点了但没到账」**不算失效**——那是活动本身的特性，不是脚本坏了。
- 开关同时写账户级与全局级配置（`useGlobal=true` 时只写账户等于没关）。
- 记录按账号隔离，文件损坏时按空账本处理，**绝不误关**。

## 三、活动参数改成可远程热更新

以后 punchcard 规则、渲染等待、启动超时、卡片等待、落地页停留这些变了，不必等新版本。
新增一层统一的参数解析与范围钳制，把规则文件里早就写了、但一直没被代码用起来的字段真正接进驱动，
熔断阈值也一起纳入。

安全边界没有放开：**选择器、正则、判定 URL 仍留在代码里**。远程只能调「等多久 / 试几次」，
不能改「怎么算计分」；越界或类型不对的规则会被整体拒收，自动回落到内置值。

## 四、其它改进

- **新版活动盘点（默认只读）**：真机抓包后补上了连胜保护、网页 PunchCards、视觉搜索等活动的
  数据盘点能力与 RFC 6238 TOTP。写入路径默认关闭并带六道安全闸门；真机证实
  「单独发上报请求不等于计分」，所以汇总不会把 HTTP 200 说成完成。这块目前只盘点、不自动上报。
- **风控信号感知**：识别明确的机器人评分警告，命中就暂停该账号并推送；数值只记录不拦截，避免误伤。
- **搜索词与拟人化**：三个热榜源降级 + 去重 + 本地词库兜底；随机参数按账号隔离，
  不会出现「一个账号跑过，其它账号今天被跳过」。
- **报告问题入口进左侧边栏**：补上带甲虫图标的按钮，点击可定位到日志导出分区
  （此前只有分区、没有按钮）。
- **关于页新增参考项目致谢**：补上 MRS助手 作者主页与项目文档链接，第三方声明同步更新。
- 修掉一批真机才暴露的问题：调试端口参数拼错、冷启动竞态、英文进度解析、
  领取日志编号重复、一轮只做一项等；自检里几条「假绿」守卫也换成真检查。

## 五、升级说明

- 直接覆盖安装即可，配置与账号数据不受影响。
- 桌面专属任务**默认关闭**，升级后需要到「任务全局设置」自行打开。
- 安装包未做代码签名（`signAndEditExecutable: false`），Windows 可能提示「未知发布者」，属预期行为；
  校验下方 SHA256 一致即可确认文件完整。
- 更新包签名是强制校验的，本次 Release 已签名；若「检查更新」提示签名失败，
  请先确认网络代理没有改写页面内容。
