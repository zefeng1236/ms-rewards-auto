# 0.17.2

发布日期：2026-11-26 · 本版推送 Docker 镜像 `0.17.2` 与 `latest`；Windows 安装包未随本版发布。

## 新增

- **统一关闭按钮组件**：新增 `CloseButton`（关闭按钮）与 `CloseGlyph`（SVG 叉号字形）。弹窗头部、Toast 通知、标签移除、自动更新弹窗、更新提示弹窗、设置页删除目标共用同一套令牌：xs/sm/md 三档（22/30/36px）、10px 圆角玻璃按钮、默认/悬停/按压/键盘焦点/禁用/危险六种状态；深浅主题由 CSS 变量自动适配，支持减少动效偏好与高对比模式。

## 改进

- **确认弹窗改用主体玻璃界面**：`Modal.confirm`（确认弹窗接口）不再调用系统原生 `window.confirm`，改由项目 `<Modal>` 渲染；`okText`（确认按钮文字）、`cancelText`（取消按钮文字）、`danger`（危险样式）参数生效，主操作为填充按钮；长风险文案拆成段落、小标题与项目符号列表，宽度取 md 档（560px）。取消、确定、Esc、点遮罩、宿主未挂载五种情况都能结算 Promise。
- **关闭按钮焦点环跟随圆角**：原生对话框打开时会自动聚焦第一个可聚焦元素，直角 `outline` 焦点环改为圆角 `box-shadow` 环，高对比模式保留 `outline` 回退；SVG 叉号在 24 视图里由 10 单位放大到 12 单位。

## 修复

- **系统原生确认框与主体界面割裂**：白底系统对话框、系统按钮、自定义按钮文字被忽略的问题已消除；渲染层不再存在 `window.confirm` 调用，也不再存在裸 `×` 文本按钮。
- **关闭按钮四套实现并存**：移除 `.compat-modal-head button` / `.compat-toast button` 元素选择器与自绘 `.upd-close` 样式，避免旧规则以更高特异性覆盖新令牌。

## 升级方式

- **Docker 版**：compose 内置 Watchtower 每 6 小时检查 `latest` 并自动拉取重启；也可手动执行 `docker compose -f docker/docker-compose.yml pull` 后 `docker compose -f docker/docker-compose.yml up -d`。锁定版本时把 `image:` 的 `latest` 改成 `0.17.2` 并删掉 watchtower 服务。
- **Windows 版**：本版未发布安装包；发布后需手动下载安装（UAC 提权），不会自动升级。
- 桌面任务默认仍为「先通知」，三档触发方式与按账号每日手动额度未改动；桌面任务标注「实验性功能」。
