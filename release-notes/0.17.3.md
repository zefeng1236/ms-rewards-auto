# 0.17.3

发布日期：2026-11-28 · 修复版本 · 需手动下载安装（UAC 提权），旧版不会自动升级为本版。

## 新增

- **「立即完成」开关链路离线回归**：新增 `test:force-run`，覆盖 preload → IPC → 批量执行 → 单账户执行 → 任务层的开关透传；并用旧写法注入验证守卫会拦截。

## 改进

- **「立即完成」一轮补齐当天剩余任务**：批量执行层补传 force，单账户执行收到后忽略「单次执行数量」限制；阅读、积分活动、搜索在同一轮补齐服务器剩余次数。
- **搜索 force 优先于分批设置**：force 轮本轮搜索次数取服务器今日剩余次数，不受用户设定的每轮次数限制；普通轮保持用户设定或 4–7 次随机分批。
- **运行日志区分来源**：force 轮搜索日志标注「force（一轮完成）」，普通轮保持「用户设定 / 随机」。

## 修复

- **「立即完成」退化成「立即运行」**：批量执行层未把 force 传给单账户执行，二次确认后仍按分批限制运行，阅读与搜索只完成单轮配额。
- **force 轮搜索仍分批**：用户设定的每轮次数优先于 force，且 force 分支固定随机 6–9 次；当天剩余次数超过该值时一轮无法补齐。

## 升级须知

- 0.17.2 仅推送 Docker 镜像，未发布 Windows 安装包；本版桌面安装包包含 0.17.2 的确认弹窗玻璃化与统一关闭按钮改动。
- Windows 安装包需手动下载安装（UAC 提权），不会自动升级。
- Docker 版：compose 内置 Watchtower 每 6 小时检查 `latest` 并自动拉取重启；锁定版本时把 `image:` 改成 `0.17.3` 并删掉 watchtower 服务。
- 桌面任务默认仍为「先通知」，三档触发方式与按账号每日手动额度未改动；桌面任务标注「实验性功能」。
