# 0.14.9：修复 0.14.8 的启动黑屏

> 如果你装的是 0.14.8.1 且打开是黑屏，这版就是给你的。**请务必升级。**
>
> 这次一并补上 **0.14.8 的完整改动**（原 0.14.8 Release 因黑屏已撤回，
> 下面的「0.14.8 做了什么」是从 0.14.7 直接升上来的你需要的部分）。

## 先看这里：0.14.8 做了什么

如果你现在跑的是 0.14.7 或更早，下面三项是你原本会从 0.14.8 拿到的，**本版已全部包含**。

### 版本号不再一个窗口两个数

标题栏写着 `v0.14.6.1`、侧边栏底下却是 `0.14.5` —— 这种同一窗口两个版本号的问题已经修掉。

原因是版本号有两个来源：标题栏读运行时 `package.json`，而侧边栏、关于页、更新面板、更新弹窗用的是前端**打包那一刻烧进 JS 的常量**。开发时改了版本号但忘了重新构建前端，常量就停在旧值。

现在新增了运行时版本号通道，四个展示位统一向主进程取真值，编译期常量只作预览环境回落。**以后界面上任何一处看到的版本号，都等于真实安装的版本。**

### 安全：最后一条 CodeQL 告警清零

配置深合并那段代码补上了显式 `hasOwnProperty` 守卫。有个细节值得一提：只在循环里跳过 `__proto__` / `constructor` / `prototype` **不足以让静态分析认账** —— 它判定的是「从不可信对象读值→往目标对象写属性」这一对动作，光靠黑名单仍会被标记。这也是之前明明加了防护、告警却还挂着的原因。

### 弹窗居中（0.14.7 及更早没有）

0.14.7 及更早的构建产物里，弹窗样式缺了 `position:fixed + inset:0 + margin:auto`，弹窗会**贴着窗口底部**出现。0.14.8 起已修好，本版同样包含。

### CI：一条一直在假绿的守卫

有条校验「发布说明的 Markdown 语法渲染器都认得」的守卫，测试样本被放在了被 `.gitignore` 排除的目录里 —— 后果是本地永远绿、CI 永远红，而红的原因与代码质量毫无关系。样本已移入 `scripts/fixtures/` 正常入库，并新增前置守卫把「读不到样本」和「语法不支持」两种失败明确区分开。

## 黑屏：不是崩溃，是界面根本没渲染

0.14.8 改「版本号统一来源」时，一段 `useState` 被误放到了**模块顶层**（也就是组件外面）。

React 只在组件渲染期间提供 dispatcher（那个"当前正在渲染哪个组件"的状态）。顶层调用拿不到它，返回 `null`，React 直接抛错、**整棵界面树都不渲染** —— 窗口于是只剩背景色，看起来就是纯黑。

有意思的是这类错误**类型检查和构建都不会报**，只在运行时炸，症状又只是"黑屏"这种不好定位的样子。现在加了自动检查：扫描全部前端源码，模块顶层一旦出现 React hook 就判失败，顺带把当初写错的那两个文件钉死。

## 更新链路的老毛病也一并修了

### 每次启动都重下同一个安装包

日志里实测连下三次 100MB 的包，而安装包明明就在那儿。

原因是"已下好待装"的判定**同时要求版本号字段非空**，而那个字段因为界面层没传参一直是空的 —— 于是每次启动都判"没下好"。现在改成只看安装包本身，版本号缺失时从文件名反解。

### 已装新版，却还在弹更低的"新版本 X 已就绪"

覆盖安装新版后，配置里记录的待装安装包**还指着被取代的旧包**，而弹窗逻辑只判「文件存在 + 校验通过」，**从不比较它和当前版本的高低**。于是已经装到 0.14.9，启动后照样弹一个"新版本 0.14.8.1 已就绪"。

现在弹窗前会先比版本：待装包的版本 **≤ 当前版本** 就判为过期，直接清标记并删掉文件，不再打扰。

### 点「立即安装」打不开，现在有据可查

此前启动安装器的所有输出都被丢弃，界面上表现为"点了没反应"，日志里也查不到任何原因。现在会记录启动失败的真实原因（是否被 UAC 拒绝、是否被安全软件拦截）。

> 已知限制：UAC 对话框点"否"的情况下，启动器本身是成功退出的，日志只能告诉你"启动了但目标没起来"。要彻底定位需要换用另一套系统调用，这版还没做。

## 代码扫描恢复正常

之前手动添加的扫描工作流文件与 GitHub 内置配置**互斥**，两者并存导致每次扫描都失败。已经删掉，恢复用内置配置（那 15 条历史告警本来就是它扫出来的）。

## 升级

安装包文件名见下表，直接覆盖安装即可，配置与账号数据不受影响。

> 从 0.14.8 升级前建议先在「关于」页确认一下 —— 如果你那个版本是黑屏，那说明界面没渲染，
> 可能要找一下「关于」在哪个菜单（正常是在左下角版本号那里点一下）。
>
> **升级后如果还看到"新版本 0.14.8.x 已就绪"的弹窗**，那是旧残留，本版已修；
> 极端情况下手动清一下 `%APPDATA%\ms-rewards-auto\updates\` 目录亦可。
