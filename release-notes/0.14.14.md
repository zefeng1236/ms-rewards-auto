# 0.14.14：推送终于能好好读了

这一版只做一件事：**把推送消息的排版重做了一遍**。

起因是你在钉钉上看到的那条消息 —— 用户名和后面的正文黏成了一行，开头多出几个圆点，
版本号被挤到下一行。这一版全部修掉，并且每一条改动都在**真实的钉钉和企业微信上发过验证**，
不是纸上推演。

---

## 一、钉钉把多行压成一行（真 bug，不是观感问题）

**根因**：钉钉和企业微信的 markdown **不认单个换行符，只认空行分段**。

之前我只在「段与段之间」加了空行，段内还是用单换行连接 —— 等于只做对了一半。
于是同一段里的多行在钉钉被压成一行，用户名和警示句就黏在了一起。

现在每一行独立成块。

## 二、四项排版调整

| 之前 | 现在 |
|---|---|
| `用户名：纵明轩　　v0.14.13`（两个**全角**空格，窄屏会把版本号挤到下一行） | 两个**半角**空格 |
| 用户名行变成列表项，渲染成 `• 用户名：…` | 用户名行不转列表项 |
| 头部和正文之间没有分隔 | 中间加了一条分割线 |
| 标签是 `**加粗**` | 标签改成 `` `等宽` ``，字段名和值一眼分得开 |

## 三、每日一言拆成两个独立开关

原来**一个开关同时管两件事**：界面上显不显示、推送里附不附加 —— 而且「显示位置」
这种纯外观设置也挤在任务设置里。现在拆开：

- **软件设置 → 个性化**：界面开关 + 显示位置 + 句子类型（新增一个「每日一言」区块）
- **任务全局设置 → 推送通知**：只剩一个「推送附加一言」

**关一边不影响另一边** —— 关掉界面显示，推照旧带一言；关掉推送，界面照旧显示。

⚠️ 如果你以前关过「推送附加一言」，升级后**仍然是关着的**。这里专门做了迁移：
配置合并时容易把「用户明确关过」当成「没设置过」用默认值打开，
那种悄悄复活用户设置的情况最难察觉，现在不会了。

## 四、企业微信可以退回纯文本（**默认已关闭**）

企微群消息可以被**转发到微信客户端**，而微信不支持 markdown ——
收到的是「**标题**」「`字段`」这种带标记的裸文本，很难读。

所以「任务全局设置 → 推送通知」多了一个「**企业微信 Markdown 排版**」开关，
**默认关闭**（走纯文本）。钉钉和飞书不受影响，它们的客户端都支持 markdown。

> 想要彩色排版可以打开这个开关，但转发到微信时就会看到标记 —— 两者只能选一个。

## 五、区域拦截推送信息更全了

```
⚠️ 检测到非中国大陆区域（由 ipsb 判定），本次任务已取消执行
🟥 当前 IP：8.8.8.8
🇺🇸 Mountain View/US(美国)
🏢 Google
🕐 下次执行时间：10-09 09:55
```

- **加了运营商**（`🏢 Google`）。以前只看 IP 归属地，分不清
  「是代理节点换了」还是「家里宽带出口变了」；现在一眼能看出来。
- **归属地前面加了国旗**。香港 / 澳门 / 台湾是中国的一部分，统一用中国国旗。
- **IP / 归属地 / 运营商各占一行**，不再挤在一行；行首各带图标，不带圆点。

**关于红色**：三家平台里**只有企业微信（markdown 模式）支持文字上色**，
钉钉和企微纯文本都不支持 —— 那两条渠道用红色方块 🟥 表达。

## 六、顺带修两处文案 bug

- 目标名叫「每日目标」时，会拼成「每日目标**目标**」…
- 倍数文案从「每日目标当前已达成42.8倍目标」改成
  「每日目标已达成，当前为目标的 42.8 倍（6338/20000）」。
