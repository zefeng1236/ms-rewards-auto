### 🩹【修复】自动更新下载不再卡死

弱网下点「下载更新」经常停在某个百分比不动，进度条再也不走，界面也没有任何报错 —— 只能关掉重来。

根因有三层，本次一并解决：

- **空闲超时**：连接半死时 `fetch` 不报错也不返回，程序就在那里永久等待。
  现在 **30 秒收不到任何字节即判定停滞**，自动断开并换下一个镜像节点。
- **断点续传**：失败、换源、甚至手动取消后重新下载，都从断点继续，不用每次从 0 重来。
  镜像忽略 Range 请求时会自动识别并整体重下，不会拼出坏文件。
- **写盘错误立即失败**：磁盘写满 / 权限不足时立刻报错，而不是干等一个永远不来的回调。

另补安装包完整性校验：某些镜像出错时会返回 **200 状态码 + 一个 HTML 错误页**（体积还特别小）。
这种「假安装包」现在会被识别拒掉，不会装到一半才出问题。

修复后的下载链路长这样：

```text
空闲 30s 无字节 → 判定停滞 → 断开 → 自动换下一个镜像节点
下载中断       → 保留 .part 半成品 → 新节点接管时带 Range 续传
收到 HTML 页面 → MZ 魔数校验拦下 → 换源（不会装到一半才炸）
全部节点失败   → 保留半成品，下次点下载从断点继续
```

> 「下载中显示百分比但一直不动」是这个版本之前最常见的反馈，现在它会被自动识别并换源。

### 🔒【安全】GitHub Code scanning 15 条告警清零

- **主题色注入风险**：外观设置里的主题色会拼进界面模板，已加白名单校验（只接受合法颜色格式），非法值回落默认色。
- **原型链污染**：设置合并逻辑会跳过 `__proto__` / `constructor` / `prototype` 三个危险键。
- **URL 校验改精确比对**：四处「判断是不是官方域名」的写法可被 `cdn.npmmirror.com.evil.com` 这类伪装域名绕过，改为解析 URL 后比对主机名。
- **正则转义补全**：五处只转义了点号（括号、星号等元字符仍可注入），改为完整转义。
- **CI 权限最小化**：两个 job 补上只读权限声明。

> Dependabot 另报的 2 条（sprintf-js / http-cache-semantics）均为 electron-builder 的**构建期传递依赖**，不进安装包运行时产物。

### 🎨【改进】双内核切换改成卡片

上一版把两个内核做成了下拉选择，但它和「拟真种子 / CPU 核数 / 操作系统 / 镜像源」排在一起、长得也一样，**很多人根本找不到「这是切内核的地方」**。

现在改成两张并排卡片：

- **当前使用的** → 主题色高亮 + 标注「当前」
- **另一个** → 点一下就切（自动下载 + 按「只保留单个内核」开关卸载旧的）
- **fingerprint-chromium 150** → 灰显但仍列出（上游 canvas 像素读取会导致崩溃，issue #94），悬停可看到原因

### 🛠【修复】界面与安装体验

- **弹窗居中**：首次启动的更新提示、更新对话框不再偏到顶部（部分环境下原生居中失效）。
- **软件设置侧栏新增「更新」分类**：自动更新相关设置此前没有独立入口。
- **安装不再被系统拦截**：点「立即安装」现在会正常弹出权限确认。此前走的启动方式不会弹权限请求，无签名安装包容易被 Windows 智能应用控制拦下、需要每次手动放行。
- **README 修正**：具体访问域名统一改为「项目需要访问的必要域名」（单一来源维护），并修掉一段 Markdown 因符号相邻导致的渲染错乱。
- **向导提示纠正**：原文写「软件设置 → 环境拟真浏览器」，实际分类名是「浏览器」。
